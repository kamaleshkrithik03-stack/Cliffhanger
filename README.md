# CliffHanger
this is a random ahh game i got from my random ahh idea derived from the original one and only hangman and the egg drop challenge. This project was built for terra. Idk why but i thought it was gonna be easy and straightforward but boy of boy was i wrong. SOOOO many errrors and scaling issues.

## How to play
alright simple [R] for rest if u fail and trust me when i say u wont beat the level 6 so ur gonna need it. to start each levels press a/s to run off the cliff left or right (reccomended left) then draw a structure by pressing left click while drawing. Any line draw above the sprite acts as a parachute and below as a spring to dampen the falls. enter to do to nxt levels and space to drop prematurely.

## How to run 
download the zip and just run the .exe
